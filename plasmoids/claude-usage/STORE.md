## Description

```
See how much of your Claude plan you have used, right in the Plasma panel: the 5-hour session limit and the weekly limit, with the time left before each one resets. Same numbers as the /usage command of Claude Code.

Features
- 4 panel designs, chosen with a live preview: Rings, Twin rings, Bars, Text
- Click for details: reset times, model-specific weekly limits, usage split by app
- Colors: terracotta, theme accent, green or any custom color
- Turns orange then red near a limit (adjustable thresholds)
- Adjustable text color, for any panel theme
- English, French, Spanish and Norwegian, selectable in the settings
- Horizontal and vertical panels, and the desktop

Requirements
- Plasma 6
- Claude Code signed in with a Claude Pro or Max account (the widget reuses its sign-in)
- curl, and jq or python3

If the numbers stop updating, open Claude Code once to renew the sign-in.

Unofficial widget, not affiliated with Anthropic.
Source code and bug reports: https://github.com/Elwynn18/plasma-widgets
```
